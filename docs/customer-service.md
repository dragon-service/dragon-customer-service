# Dragon NaturallySpeaking Customer Service

Dragon NaturallySpeaking users may have questions about installation,
activation, software settings, dictation, microphones, and general
troubleshooting.

This guide provides general informational help for common issues.

## Common Customer Service Topics

### Installation

Installation problems can occur because of system compatibility,
permissions, previous installations, or software requirements.

### Activation

If the software does not activate correctly, first verify that the
software version and account information are correct.

### Microphone Problems

A microphone that is not configured correctly can affect speech
recognition. Check the microphone connection and Windows audio settings.

### Dictation Problems

If Dragon NaturallySpeaking does not recognize speech accurately,
check the microphone, audio input, and recognition settings.

## Before Seeking Further Help

Try these basic steps:

1. Restart the computer.
2. Restart Dragon NaturallySpeaking.
3. Check the microphone connection.
4. Review the available software updates.
5. Verify that Windows recognizes the microphone.
