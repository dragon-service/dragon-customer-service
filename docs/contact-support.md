# Dragon NaturallySpeaking Contact Support Guide

If you are experiencing an issue with Dragon NaturallySpeaking, it can
help to identify the type of problem before looking for assistance.

## Common Reasons Users Seek Support

Users may need help with:

- Installation
- Activation
- Account-related questions
- Microphone configuration
- Speech recognition
- Software updates
- Compatibility questions
- General troubleshooting

## Before Contacting Support

Collect some basic information about the issue:

1. The Dragon NaturallySpeaking version you are using.
2. Your Windows version.
3. A short description of the problem.
4. Any error message that appears.
5. Steps you have already tried.

Having this information ready can make troubleshooting easier.

## General Troubleshooting

Before seeking additional assistance, try restarting the application
and computer. Also check that your microphone is connected correctly
and recognized by Windows.

## Official Support

This website is an independent informational guide and is not an
official Dragon NaturallySpeaking or Nuance customer support website.

For official assistance, users should refer to the publisher's official
