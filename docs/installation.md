# Dragon NaturallySpeaking Installation Guide

Installing Dragon NaturallySpeaking involves preparing the computer,
checking compatibility, and following the installation process for the
software version being used.

## Before Installation

Before starting the installation, check the following:

- Windows is updated.
- There is enough available storage space.
- The computer meets the software requirements.
- Any required account information is available.
- The microphone is connected if you plan to use dictation.

## Installation Preparation

Close unnecessary applications before beginning the installation.

If an older version of the software is already installed, review the
available documentation before removing or replacing it.

## Installation Process

The general installation process may include:

1. Obtain the appropriate software installer.
2. Start the installer.
3. Follow the on-screen instructions.
4. Allow the installation to complete.
5. Restart the computer if requested.
6. Open Dragon NaturallySpeaking and complete any required setup.

The exact process may vary depending on the software version.

## After Installation

After installation, check that:

- The application opens normally.
- Windows recognizes the microphone.
- The correct audio input is selected.
- Required account or activation steps are completed.
- Dictation works as expected.

## Installation Problems

If installation fails, note the exact error message.

You can also restart the computer and try the installation again after
checking available storage, Windows updates, and software compatibility.
